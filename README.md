# Satvik C - Career Universe

An immersive React + Three.js portfolio for senior data engineering, financial platforms, backend development, and independent AI demonstrations.

## Development
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm run preview
```

The Vite build outputs to `dist/`. Deploy this directory on Replit, Vercel, or Netlify. For Replit, choose a static deployment with build command `npm run build` and public directory `dist`.

## Portfolio data

The professional roles, metrics, and technologies are based on the supplied resume PDF. FinShift AI and Risk Insights Platform are independent demonstrations using synthetic data, not real financial customer records. Current employer dates appear as listed on the resume and should be verified before sharing.

The contact form launches a prefilled email in the visitor's mail client; it is not a backend submission endpoint. There is no invented LinkedIn address or educational credential.

Project repository: https://github.com/satvik66/portfolio-SC
FinShift AI: https://github.com/satvik66/samplefinsh-ai

## Design
Uses React 19, Vite, React Three Fiber, Drei, and Lucide icons. Canvas animation is disabled for small screens and reduced-motion preferences, and the layout is responsive.
